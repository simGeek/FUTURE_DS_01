# SOCIAL MEDIA TREND ANALYSIS

AIM

To analyze the trending topics on Twitter to understand user interests and market shifts.

SKILLS

Power BI
Python (pandas)
Jupyter Notebook
Natural Language Processing
Sentiment Analysis (vaderSentiment)
Web Scraping (BeautifulSoup and Selenium)

WORKFLOW

1) Scraped the twitter website with login credentials, advanced search urls, beautifulSoup and selenium.
2) Extracted the tweets, date of posting, number of likes and main hashtag.
3) Created separate dataframes for four trending topics.
4) Concatenated into a single dataframe for effective data analysis.
5) Performed basic 'Natural Language Processing' for data preprocessing.
6) Calculated Compound Score with VaderSentiment to determine whether the tweet is 'positive', 'negative' or 'neutral'.
7) Created the final dataframe suitable for further analysis and dashboard creation in Power BI.
8) Imported the csv in Power BI and designed a dashboard highlighling important insights.
